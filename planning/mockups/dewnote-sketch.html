One document, dressed three ways

The window below is a single manuscript. The settings rail (⚙, open by default) doesn't pick a theme so much as tune variables that already exist — Workshop is dewnote's own resting look, Manuscript reproduces dewlab's real tokens for an honest preview, Chalkboard commits to dark. Drag the sliders after choosing one; nothing here is a fixed screenshot.

Click the heading, the paragraph, or the hint to edit its source. The code line has no separate render mode to click into — it's a live editor already, the same as it would be behind CodeMirror. Hover a gap between blocks for the add control, hover the cell for its own quiet toolbar, and press ▸ to re-run it.
